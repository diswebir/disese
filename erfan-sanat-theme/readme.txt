قالب سازمانی «عرفان صنعت» برای شرکت‌های نورپردازی شهری، المان نوری و محصولات دانش‌بنیان روشنایی.
A production-grade Persian (fa-IR, RTL) WordPress theme for urban lighting manufacturers.

== Description ==

قالب عرفان صنعت یک قالب نیتیو و سازمانی وردپرس است که برای شرکت‌های فعال در حوزهٔ نورپردازی شهری، المان نوری، تونل نوری و محصولات دانش‌بنیان نوشته شده است.

ویژگی‌ها:

* طراحی راست‌به‌چپ (RTL) با فونت وزیرمتن، میزبانی‌شدهٔ محلی (بدون Google Fonts و بدون CDN).
* مدل محتوایی کامل: نوع محتوای «پروژه» با دو تاکسونومی، مقالات فنی، محصولات ووکامرس.
* مدل فروش سفارشی: خرید آنلاین، استعلام تلفنی و مناقصهٔ رسمی برای هر محصول.
* پنل تنظیمات اختصاصی با ۱۷ بخش، رندرکنندهٔ فیلد مبتنی بر اسکیمای واحد، درون‌ریزی/خروجی JSON و بازنشانی بخشی.
* CSS متغیرمحور: رنگ‌ها، تایپوگرافی و شعاع گوشه‌ها در زمان اجرا به‌صورت متغیر CSS تولید می‌شوند و هیچ فایل فیزیکی نوشته نمی‌شود.
* دسترس‌پذیری: لینک پرش، منوهای قابل پیمایش با کیبورد، فوکوس نمایان، احترام به prefers-reduced-motion.
* کارایی: بارگذاری شرطی دارایی‌ها، کاهش پرس‌وجوهای تکراری، کش تنظیمات در هر درخواست.
* سازگاری با ووکامرس: بازنویسی قالب‌های ضروری، پشتیبانی از محصولات متغیر، ویژگی‌ها، سبد خرید، تسویه حساب و حساب کاربری.

== Installation ==

1. فایل ZIP قالب را از مسیر «نمایش > پوسته‌ها > افزودن پوستهٔ تازه > بارگذاری پوسته» نصب و فعال کنید.
2. از منوی «قالب عرفان صنعت» در پیشخوان، بخش‌های ۱۷گانهٔ تنظیمات را بازبینی کنید.
3. از «ابزارها و وضعیت» می‌توانید محتوای نمونه (پروژه‌ها، صفحات، مقالات)، برگه‌ها، منوها و ساختار فروشگاه را بسازید.
4. برای فروشگاه، افزونهٔ WooCommerce را نصب کنید و از همان صفحه دکمهٔ «راه‌اندازی فروشگاه» را اجرا کنید.

== Frequently Asked Questions ==

= آیا قالب به افزونهٔ صفحه‌ساز نیاز دارد؟ =
خیر. تمام بخش‌ها با وردپرس نیتیو، بلوک‌های استاندارد و قالب‌های سفارشی ساخته شده‌اند؛ هیچ صفحه‌ساز یا فریم‌ورک خارجی لازم نیست.

= دادهٔ کسب‌وکار کجا نگهداری می‌شود؟ =
محصولات، پروژه‌ها و مقالات در نوع‌های محتوای وردپرس ذخیره می‌شوند. تنظیمات قالب تنها شامل پوسته، چیدمان و اطلاعات تماس است.
